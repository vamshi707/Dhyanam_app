# 🧘 Dhyanam App

A simple and peaceful meditation app designed to help users relax, focus, and improve mental well-being.

---

## 📱 Features

* 🧘 Guided meditation sessions
* ⏱️ Timer for meditation practice
* 🎵 Calm background sounds
* 🌙 Clean and minimal UI
* 📊 Track your meditation time

---

## 🚀 Tech Stack

* **Frontend:** React + Vite
* **Mobile:** Capacitor (Android)
* **Language:** TypeScript
* **Styling:** CSS / Tailwind (if used)

---

## ⚙️ Installation & Setup

Clone the repository:

```bash
git clone https://github.com/your-username/dhyanam-app.git
cd dhyanam-app
```

Install dependencies:

```bash
npm install
```

Run the app:

```bash
npm run dev
```

---

## 📦 Build Android APK

```bash
npm run build
npx cap sync android
npx cap open android
```

Then in Android Studio:

* Click **Build → Build APK**
* APK will be generated in:

```
android/app/build/outputs/apk/debug/app-debug.apk
```
